## 🏗️ Featured Project

### ShikshaMatrix

A production multi-tenant School ERP SaaS platform designed to manage school operations across administration, academics, finance, transport, hostel, communication and more.

**Architecture**

- Next.js web applications
- React Native / Expo mobile application
- Fastify + TypeScript backend
- Prisma + PostgreSQL
- JWT authentication
- Role-based access control
- School-level tenant isolation
- Puppeteer-based PDF generation
- Claude-powered AI Help Center

**Production Features**

- Finance & Fee Management
- Hostel Management with bed & floor-level allocation
- Transport with live tracking
- Help Center with AI chatbot
- Settings & Billing
- Live dashboard metrics
- Student Admission workflows
- Online Examination system
- Front Office workflows
